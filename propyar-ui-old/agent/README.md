# عامل نظارت متاتریدر (MT5 Agent)

این برنامه‌ی کوچک، حساب‌های معاملاتی را از خود متاتریدر می‌خواند و به سایت
می‌فرستد. سایت با همان داده، قوانین را بررسی می‌کند و اگر قانونی نقض شده باشد
حساب را رد می‌کند.

**هیچ سرویس واسطه‌ای در کار نیست.** عامل فقط با سرور بروکر و با سایت خودمان حرف
می‌زند، پس از هر شبکه‌ای کار می‌کند.

---

## چه چیزی لازم است

| مورد | توضیح |
|---|---|
| یک ویندوز | کامپیوتر خودتان یا یک سرور مجازی ویندوزی |
| متاتریدر ۵ | همان نسخه‌ی معمولی دسکتاپ، نصب‌شده |
| پایتون ۳.۱۰ به بالا | از python.org |
| رمز فقط‌خواندنی هر حساب | **نه** رمز اصلی — پایین توضیح داده شده |

> کتابخانه‌ی رسمی متاتریدر فقط روی ویندوز کار می‌کند، چون خودِ ترمینال
> متاتریدر را کنترل می‌کند. اگر سایت روی لینوکس بالا آمده مشکلی نیست — عامل
> جای دیگری اجرا می‌شود و فقط داده را می‌فرستد.

---

## چرا رمز فقط‌خواندنی؟

هر حساب متاتریدر دو رمز دارد:

- **رمز اصلی (Master)** — با آن می‌شود معامله باز و بسته کرد
- **رمز فقط‌خواندنی (Investor)** — فقط می‌شود حساب را دید، امکان معامله نیست

عامل فقط نیاز به **دیدن** دارد. همیشه رمز فقط‌خواندنی بدهید. اگر این فایل جایی
درز کند، کسی نمی‌تواند روی حساب‌ها معامله کند.

رمز فقط‌خواندنی را موقع ساخت حساب دمو در پنل بروکر می‌گیرید، یا از داخل خود
متاتریدر: راست‌کلیک روی حساب ← تغییر رمز ← گزینه‌ی Investor.

## راه‌اندازی

### ۱. نصب کتابخانه‌ها

```
pip install MetaTrader5 requests
```

### ۲. ساخت فایل تنظیمات

از `config.example.json` یک کپی به اسم `config.json` بگیرید و پرش کنید:

```json
{
  "siteUrl": "https://propino.top",
  "bridgeSecret": "همان مقدار BRIDGE_SECRET در تنظیمات سایت",
  "intervalSeconds": 120,
  "historyDays": 60,
  "terminalPath": "C:\\Program Files\\MetaTrader 5\\terminal64.exe",
  "accounts": [
    {
      "login": "50231884",
      "password": "رمز فقط‌خواندنی همین حساب",
      "server": "نام سرور بروکر"
    }
  ]
}
```

- **siteUrl** — آدرس سایت. برای تست روی همین کامپیوتر: `http://localhost:3000`
- **bridgeSecret** — باید **دقیقاً** با `BRIDGE_SECRET` در فایل `.env` سایت یکی باشد
- **intervalSeconds** — هر چند ثانیه یک بار همه‌ی حساب‌ها خوانده شوند
- **historyDays** — چند روز تاریخچه‌ی معاملات خوانده شود
- **server** — نام سروری که در پنجره‌ی ورود متاتریدر می‌بینید، مثل `Alpari-Demo`

### ۳. اجرا

```
python mt5_agent.py
```

خروجی چیزی شبیه این است:

```

[2026-08-09 14:22:01]

  ✓ 50239912: equity 54200.00 · 0 open · 8 closed

```

## اجرای دائمی

برای اینکه با هر بار روشن شدن ویندوز خودکار اجرا شود:

1. یک فایل `start-agent.bat` بسازید:
   ```
   cd /d "%~dp0"
   python mt5_agent.py
   ```
2. `Win + R` را بزنید و `shell:startup` را وارد کنید
3. یک میان‌بر از فایل bat را در آن پوشه بگذارید

## مشکلات رایج

| پیام | معنی و راه‌حل |
|---|---|
| `Could not start the MT5 terminal` | مسیر `terminalPath` اشتباه است، یا متاتریدر نصب نیست |
| `login failed` | رمز یا نام سرور غلط است. نام سرور را عیناً از پنجره‌ی ورود متاتریدر کپی کنید |
| `account ... is live on the site but not in config.json` | سایت حسابی دارد که در تنظیمات عامل نیست — اضافه‌اش کنید |
| `403` هنگام ارسال | `bridgeSecret` با `BRIDGE_SECRET` سایت یکی نیست |
| `503 bridge_not_configured` | در `.env` سایت مقدار `BRIDGE_SECRET` خالی است |

---

## نکات امنیتی

- `config.json` رمز دارد. جایی نگذارید که دیگران ببینند و در گیت commit نکنید
  (از قبل نادیده گرفته شده است)
- `BRIDGE_SECRET` را یک رشته‌ی تصادفی بلند بگذارید، نه یک کلمه‌ی ساده
- اگر سایت روی HTTPS است، `siteUrl` را هم با `https://` بنویسید تا داده رمزنگاری
  شود
