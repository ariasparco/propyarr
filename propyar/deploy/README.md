# راه‌اندازی سایت روی سرور

سه مرحله. کل کار حدود ۲۰ تا ۳۰ دقیقه طول می‌کشد که بیشترش منتظر ماندن است.

---

## مرحله ۱ — اتصال به سرور

روی کامپیوتر خودت:

1. `Win + R` را بزن و `mstsc` را وارد کن
2. آدرس سرور را بنویس: `91.228.186.234`
3. نام کاربری `Administrator` و رمز سرور را وارد کن

> **اولین کاری که روی سرور می‌کنی:** رمز ادمین را عوض کن.
> `Ctrl + Alt + End` را بزن و «Change a password» را انتخاب کن.

---

## مرحله ۲ — انتقال فایل‌ها

پوشه‌ی `propino-deploy` را از کامپیوتر خودت کپی کن و روی سرور در مسیر زیر بگذار:

```
C:\propino
```

ساده‌ترین راه: پوشه را در کامپیوتر خودت `Ctrl+C` کن و داخل پنجره‌ی ریموت‌دسکتاپ `Ctrl+V` کن.

اگر کپی/پیست کار نکرد، موقع اتصال در پنجره‌ی `mstsc` روی **Show Options → Local Resources → More** برو و تیک درایو `C` را بزن؛ آن‌وقت درایو کامپیوترت داخل سرور دیده می‌شود.

بعد از کپی، ساختار باید این‌طور باشد:

```
C:\propino\
    package.json
    prisma\
    src\
    deploy\
    env-template.txt
```

حالا فایل `env-template.txt` را به `.env` تغییر نام بده:

```
C:\propino\.env
```

---

## مرحله ۳ — اجرای اسکریپت نصب

روی سرور، **PowerShell را به‌صورت Administrator** باز کن و این را اجرا کن:

```powershell
cd C:\propino
powershell -ExecutionPolicy Bypass -File deploy\setup.ps1
```

این اسکریپت خودش همه‌ی این‌ها را نصب و تنظیم می‌کند:

| مورد | توضیح |
|---|---|
| Node.js | آخرین نسخه‌ی LTS |
| PostgreSQL | دیتابیس، به‌همراه کاربر و رمز اختصاصی |
| کلیدهای امنیتی | چهار کلید جدید و تصادفی می‌سازد |
| ساخت سایت | نصب وابستگی‌ها و بیلد |
| سرویس ویندوز | سایت با هر بار ری‌استارت خودکار بالا می‌آید |
| Caddy | گواهی HTTPS را خودکار می‌گیرد و تمدید می‌کند |
| فایروال | پورت‌های ۸۰ و ۴۴۳ را باز می‌کند |

اگر جایی خطا داد، فایل `C:\propino\setup.log` را بفرست.

---

## مرحله ۴ — اتصال دامنه

در پنل DNS دامنه (لیارا)، یک رکورد بساز:

| نوع | نام | مقدار |
|---|---|---|
| A | `@` | `91.228.186.234` |
| A | `www` | `91.228.186.234` |

بین چند دقیقه تا چند ساعت طول می‌کشد. به‌محض اینکه دامنه به سرور اشاره کند، Caddy خودش گواهی HTTPS را می‌گیرد — کاری لازم نیست.

---

## مرحله ۵ — ساخت حساب مدیر

بعد از اینکه سایت بالا آمد:

```powershell
cd C:\propino
powershell -ExecutionPolicy Bypass -File deploy\seed.ps1
```

ایمیل و رمز مدیر را از تو می‌پرسد و حساب‌های نمونه را حذف می‌کند.

## بررسی وضعیت

```powershell
Get-Service propino, caddy, postgresql
```

هر سه باید `Running` باشند.

لاگ‌ها:

```
C:\propino\app.log      خود سایت
C:\propino\caddy.log    گواهی و HTTPS
C:\propino\setup.log    مراحل نصب
```

ری‌استارت سایت بعد از تغییرات:

```powershell
Restart-Service propino
```

## عامل نظارت متاتریدر

این برنامه حساب‌ها را از متاتریدر می‌خواند و به سایت می‌فرستد تا قوانین
بررسی شوند.

### گام ۱ — متاتریدر ۵ را نصب کن

از سایت بروکر خودت دانلود و نصب کن. نصب‌کننده‌اش پنجره دارد و نمی‌شود
خودکارش کرد.

### گام ۲ — اسکریپت را اجرا کن

```powershell
cd C:\propino
powershell -ExecutionPolicy Bypass -File deploy\agent-setup.ps1
```

خودش پایتون و کتابخانه‌ها را نصب می‌کند، `config.json` را می‌سازد و
**کلید امنیتی را از `.env` سایت برمی‌دارد** — لازم نیست دستی کپی کنی.

### گام ۳ — حساب‌ها را اضافه کن

```powershell
notepad C:\propino\agent\config.json
```

برای هر حساب:

```json
{
  "login": "شماره حساب",
  "password": "رمز فقط‌خواندنی",
  "server": "نام سرور بروکر"
}
```

> **حتماً رمز فقط‌خواندنی (Investor)** بده، نه رمز اصلی. با رمز فقط‌خواندنی
> فقط می‌شود حساب را دید و امکان معامله نیست.
>
> نام سرور را عیناً از پنجره‌ی ورود متاتریدر کپی کن.

### گام ۴ — اجرا

```powershell
Start-ScheduledTask -TaskName 'PROPINO Monitoring Agent'
Get-Content C:\propino\agent.log -Wait -Tail 20
```

باید چیزی شبیه این ببینی:

```
✓ 50231884: equity 10870.00 · 1 open · 8 closed
→ sent 1 account(s)
```

## ⚠️ مهم‌ترین نکته درباره‌ی عامل

متاتریدر برای کار کردن به یک **نشست دسکتاپ زنده** نیاز دارد. برای همین
عامل به‌صورت سرویس ویندوز اجرا نمی‌شود، بلکه با ورود شما بالا می‌آید.

وقتی کارت با ریموت‌دسکتاپ تمام شد:

| کار | نتیجه |
|---|---|
| ✅ دکمه‌ی **X** پنجره را بزن (Disconnect) | نشست زنده می‌ماند، عامل کار می‌کند |
| ❌ **Sign out** بزنی | نشست بسته می‌شود، متاتریدر و عامل می‌خوابند |

اگر سرور ری‌استارت شد، باید یک بار با ریموت‌دسکتاپ وارد شوی تا عامل دوباره
شروع کند. اگر می‌خواهی این هم خودکار شود، ورود خودکار ویندوز
(Auto-logon) را فعال کن.

### اگر عامل خاموش بماند چه می‌شود؟

سایت نمی‌شکند. فقط داده‌ی حساب‌ها کهنه می‌ماند و در پنل ادمین با برچسب
کهربایی «بدون داده» نشان داده می‌شود. دکمه‌ی «بررسی اکانت» و بررسی خودکار
هر ۵ دقیقه سر جایشان هستند.
