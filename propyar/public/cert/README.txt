Certificate assets
==================

background.png  (optional)
    The designer's artwork, 1620 x 1080. Drop it in and the renderer uses it as
    the ground, drawing only the text on top -- that is how to get the original
    artwork exactly. Without it the ground is drawn in code in the same palette.
    background.jpg works too. Restart the service after adding or changing it;
    the file is read once and kept in memory.

Cinzel-400.ttf, Cinzel-700.ttf, GreatVibes-Regular.ttf
    Display serif and script faces. Both are SIL Open Font License 1.1, which
    permits bundling and commercial use. Persian names fall back to Vazirmatn,
    which ships with the app.
